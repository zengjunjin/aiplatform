这是一个测试文档，用于 RAG Platform 文档管理 API 测试。

RAG（Retrieval-Augmented Generation）是一种结合检索和生成的 AI 技术架构。
它通过从知识库中检索相关文档片段，然后使用大型语言模型生成答案。

RAG 的主要优势包括：
1. 减少幻觉：基于真实文档生成回答，降低模型编造信息的可能性
2. 知识更新：无需重新训练模型，只需更新知识库即可
3. 可溯源性：每个回答都可以追溯到具体的来源文档

RAG 系统的核心组件：
- 文档解析器：支持 PDF、DOCX、Markdown、TXT 等格式
- 文本分块器：将长文档切分为适合检索的小块
- 嵌入模型：将文本转换为向量表示
- 向量数据库：存储和检索向量
- 重排序器：对检索结果进行二次排序
- 大语言模型：基于检索到的上下文生成最终回答

这是一个完整的端到端 RAG 平台，支持多用户、多知识库管理。
