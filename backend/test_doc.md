# Python FastAPI RAG Platform Test Document

## Introduction
This is a test document for the RAG platform testing.
It contains multiple sections with various topics.

## What is FastAPI
FastAPI is a modern, fast web framework for building APIs with Python.
It is based on standard Python type hints and supports async/await.
FastAPI automatically generates OpenAPI documentation.

## What is RAG
RAG stands for Retrieval-Augmented Generation.
It combines retrieval systems with large language models.
RAG improves answer quality by grounding responses in relevant documents.

## Vector Databases
Chroma is an open-source embedding database.
It stores vector embeddings for similarity search.
Vector databases enable semantic search capabilities.

## Ollama
Ollama is a tool for running large language models locally.
It supports models like Llama, Qwen, Mistral and many more.
bge-m3 is a multilingual embedding model by BAAI.

## BM25 Retrieval
BM25 is a keyword-based retrieval algorithm.
It uses term frequency and inverse document frequency.
Hybrid retrieval combines BM25 with vector search.

## Conclusion
The RAG platform integrates all these components.
It provides a complete solution for knowledge base question answering.
