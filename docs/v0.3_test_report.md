4. **认证流程**：access_token 仅内存存储，通过 refreshToken 调用 `/auth/refresh` 获取，符合设计

#### 测试中发现并修复的问题

| 问题 | 严重度 | 根因 | 修复 |
|------|--------|------|------|
| Reranker 模型加载失败 `np.long`/`np.ulong` | ERROR | numpy 1.24+ 移除别名，scipy/transformers 仍引用 | `reranker_provider.py` 添加 monkey-patch 补回 8 个别名 |
| FastAPI instrumentation failed | WARNING | `FastAPIInstrumentor.instrument_app()` 在 lifespan 中调用，app 已启动 | 移到 `app = FastAPI(...)` 创建后立即调用 |
| WebSocket ping timeout 每 30s | WARNING | 前端 pingInterval=30s 与服务端 recv_timeout=30s 竞态 | 前端 pingInterval 改为 20s，留 10s 余量 |
| Reranker `_load_event.set()` NoneType | ERROR | except 分支清空 `self._load_event` 后 finally 调用 `.set()` | 用局部变量 `event` 保存引用，finally 中 set 局部变量 |
| low-rated API 400 错误 | 400 | 前端 `page_size=1000`，后端限制 `le=100` | 后端上限改为 `le=1000` |
| WebSocket 心跳 `pong_event` KeyError | ERROR | `heartbeat_state` 初始化缺少 `pong_event` | 初始化时添加 `"pong_event": asyncio.Event()` |
