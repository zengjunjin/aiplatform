def _embed_and_store(doc_id: int, chunks: list[dict]) -> None:
    """Embed all chunks and store in Qdrant + rebuild BM25 index."""
    if not chunks:
        return

    texts = [c["content"] for c in chunks]
    kb_id = chunks[0]["kb_id"]

    loop = asyncio.new_event_loop()
    try:
        vectors = loop.run_until_complete(_embed_texts_async(texts))

        async def _add():
            await retriever.add_chunks(kb_id, chunks, vectors)

    try:
        from sqlalchemy import update as sa_update

            if chunk_id is None:

            point_id = str(chunk_id)
            session.execute(
                sa_update(DocumentChunk)
                .where(DocumentChunk.id == chunk_id)
                .values(vector_id=point_id)
            )
        session.commit()
    finally:
        session.close()

**问题描述**：
- [chunker.py:66-71](file:///c:/Users/15116/Desktop/aiplatform/backend/app/parsers/chunker.py#L66-L71)
- `_find_split_pos` 只查找 `。?!;\n` 作为句子边界
- 缺少英文句号 `.`、感叹号 `!`、问号 `?` 的支持
- 找不到边界时直接在 target 位置截断，可能切断 URL 或代码

**修改文件**：
- `backend/app/parsers/chunker.py`

**修改内容**：
```python
def _find_split_pos(self, text: str, target: int) -> int:
    """在 target 附近找最近的句子边界（中英文兼容）"""
    # 优先查找句子边界
    for i in range(min(target, len(text)), max(0, target - 100), -1):
        if text[i] in "。.!?！？;\n":
            return i + 1
    # 其次查找空格边界（避免切断 URL/代码）
    for i in range(min(target, len(text)), max(0, target - 100), -1):
        if text[i] in " \t":
            return i + 1
    # 最后才在 target 位置截断
    return target
```

**验收标准**：
- [ ] 中英文混合文本分块正确

### T9: 前端 API 请求重试机制

**问题描述**：
- [client.ts](file:///c:/Users/15116/Desktop/aiplatform/frontend/src/api/client.ts)
- 前端 API 客户端没有请求重试逻辑
- 网络抖动时直接失败，用户体验不佳

**修改文件**：
- `frontend/src/api/client.ts`

**修改内容**：
```typescript
// 添加重试拦截器（仅对 GET 请求，最多重试 2 次）
client.interceptors.response.use(
  (response) => response,
  async (error) => {
    const config = error.config;
    if (!config || config.__retryCount >= 2) return Promise.reject(error);
    if (error.response?.status >= 500 || error.code === 'ECONNABORTED') {
      config.__retryCount = (config.__retryCount || 0) + 1;
      await new Promise(resolve => setTimeout(resolve, 1000 * config.__retryCount));
      return client(config);
    }
    return Promise.reject(error);
  }
);
```

**验收标准**：
- [ ] GET 请求在 5xx 错误时自动重试 2 次
- [ ] 重试间隔指数退避（1s, 2s）
- [ ] POST/PUT/DELETE 不重试（避免重复写入）
- [ ] 前端单元测试通过
- [ ] 回归：正常 API 调用不受影响

**监测点**：
- 网络面板：失败请求自动重试
